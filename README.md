# Women's Safety Alert System — ML Prototype

## Overview
A beginner-friendly ML assignment comparing Decision Tree and K-Nearest Neighbors (KNN) on **synthetic example scenarios**. The proposed app concept includes a user-triggered SOS that could share location with trusted contacts or an authorized emergency service. **This notebook does not send alerts or contact police.**

## Dataset
- File: `synthetic_safety_scenarios.csv`
- Source: generated synthetically for this educational project; not real incident data.
- Target: `elevated_concern_label` (0 = routine, 1 = elevated concern).
- Features: hour of day, travelling alone, isolated area, help availability, harassment reported, reliable transport availability, and area lighting.
- Labels are generated by an illustrative rule plus noise and do not measure actual danger.

## Models and results
The notebook evaluates a Decision Tree and KNN using accuracy, classification reports, and confusion matrices on a stratified 80/20 test split.

Accuracy on the fixed split:
- Decision Tree: 74.2%
- KNN: 73.3%

The higher-scoring model on this synthetic split is **Decision Tree**. These scores demonstrate the workflow only, not real-world safety performance.

## How to run
### Google Colab
1. Upload `Womens_Safety_ML_Project.ipynb` and `synthetic_safety_scenarios.csv` to Colab.
2. Open the notebook.
3. Select **Runtime → Run all**.

### VS Code / Jupyter
1. Install Python 3.
2. Run `python -m pip install -r requirements.txt`.
3. Keep the notebook and CSV in the same folder.
4. Open the notebook and run all cells.

## Conclusion
This project practices loading data, checking missing values, preparing features and target, training two classifiers, and comparing accuracy and confusion matrices.

## Safety note
This is not a validated risk predictor or emergency service. A real app must never block or delay a manual SOS based on ML output. Live alerts require permissions, secure implementation, reliable delivery, and authorized integration. Test with simulations or consenting contacts; never send fake emergency alerts.
