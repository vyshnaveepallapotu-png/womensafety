Important safety information

This prototype does not detect real danger or send SOS alerts. The dataset is synthetic, and its labels are illustrative—not real incident data or a validated measure of risk. Accuracy scores here do not establish real-world safety performance.
  1. For immediate danger, contact local emergency services or a trusted person directly.
  2. Never wait for an ML result before seeking help or using an emergency option.
  3. A real alert feature would need careful consent, permissions, privacy protections, and reliable testing.

Run the project

The machine-learning code runs in Python through Jupyter or Google Colab; this webpage is a project overview.

  1. Open the notebook in Google Colab or Jupyter.
  2. Keep synthetic_safety_scenarios.csv in the same working folder (or upload it to Colab).
  3. Install dependencies with python -m pip install -r requirements.txt if running locally.
  4. Run the notebook cells to reproduce the model comparison.
